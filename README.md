# GaC-Srtool 🌌

เว็บแอปพลิเคชันแดชบอร์ด (Web Dashboard & Management Tool) สำหรับจัดการข้อมูลตัวละคร, จัดทีม, และไฟล์เซฟ (`freesr-data.json`, `persistent`) ของเซิร์ฟเวอร์ **GaC-hkrpg-go** (และเซิร์ฟเวอร์มาตรฐาน FreeSR)

ทำงานแบบ Client-side 100% สามารถเปิดใช้งานผ่านเบราว์เซอร์ได้ทันที

---

## ⚡ ฟังก์ชันหลัก (Features)

- **📊 แดชบอร์ด & จัดทีม (Dashboard & Lineup):** แสดงสถานะเซิร์ฟเวอร์สด, สมาชิกในทีม 4 ตำแหน่ง, พิกัดตัวละคร และสรุปจำนวนทรัพยากรในคลัง
- **👥 จัดการตัวละคร (Avatars & Character Builder):** ดูข้อมูลตัวละครทั้งหมด 99 ตัวตาม Resource เกม พร้อมปรับแต่งเลเวล (1-80), เลื่อนขั้น (0-6), ระดับ Eidolon (E0-E6), และสกิล/ร่องรอย (Traces 10/10)
- **🗡️ กรวยแสง & รีลิกส์ (Equipment):** แสดงรายการกรวยแสงและรีลิกส์ที่บันทึกไว้ในคลัง
- **💾 จัดการไฟล์เซฟ GaC (Persistent):** ตั้งค่าเพศและธาตุของตัวเอก (ผู้บุกเบิก), สายพาธของ March 7th, สวิตช์ระบบพิเศษเฉพาะของเซิร์ฟเวอร์ GaC
- **⚡ สกิลพิเศษ Ex-Rank:** จัดการเปิด/ปิดความสามารถพิเศษ Ex-Rank สำหรับตัวละครเฉพาะ
- **📝 จัดการไฟล์ JSON:** ดูและแก้ไขข้อมูลดิบของไฟล์ `freesr-data.json` และ `persistent` พร้อมระบบจัดรูปแบบและดาวน์โหลดสำรอง

## 💻 การเปิดใช้งานในเครื่อง (Local Usage)

1. **เปิดผ่านเบราว์เซอร์โดยตรง:** ดับเบิลคลิกเปิดไฟล์ `index.html` ได้ทันที

   ```bash
   npx serve .
   ```
