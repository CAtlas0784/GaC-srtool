💡 ข้อมูลโหมดเซิร์ฟเวอร์ & สำหรับผู้อื่น
⚡ GaC-hkrpg-go (Full Access):
โหมดเฉพาะของเซิร์ฟเวอร์เรา สามารถอ่านและเขียนทั้ง freesr-data.json และ persistent ได้แบบ 100% เรียลไทม์ผ่าน REST API Gateway พร้อมระบบ Ex-Rank และ Teleport
🔥 FireflyGo:
สำหรับผู้ใช้งานที่รันเซิร์ฟเวอร์ FireflyGo สามารถใช้เครื่องมือนี้จัดทีม, แม็กซ์ตัวละคร, หรือปรับแต่งอาวุธ/รีลิกส์ แล้วสั่งซิงค์ผ่าน /srtools หรือกดดาวน์โหลดไฟล์ freesr-data.json ไปวางในเซิร์ฟเวอร์ได้ทันที
🕊️ RobinSR:
สำหรับผู้ใช้งาน RobinSR สามารถใช้เครื่องมือนี้ในการสร้างเซฟและตัวละครตามมาตรฐาน FreeSR ได้อย่างสมบูรณ์แบบ
