🌐 วิธีนำขึ้นโฮสต์ GitHub Pages (ฟรี 100%)

สามารถเปิดใช้งานเว็บนี้บนอินเทอร์เน็ตได้โดยไม่ต้องเสียค่าโฮสต์ใดๆ

  1. 1. สร้าง Repository บน GitHub:
    สร้าง GitHub Repo ใหม่ (Public หรือ Private ก็ได้) เช่นชื่อ GaC-srtool
  2. 2. Push โฟลเดอร์นี้ขึ้น GitHub:
    git remote add origin https://github.com/<user>/GaC-srtool.git
    git add . && git commit -m "Init GaC-srtool" && git push -u origin main
  3. 3. เปิดใช้งาน GitHub Pages:
    เข้าไปที่ Repo บน GitHub > Settings > Pages
    ใต้หัวข้อ Build and deployment เลือก Source เป็น Deploy from a branch > เลือก Branch: main, Folder: / (root) > กด Save
  4. 4. ใช้งานได้ทันที:
    เว็บจะออนไลน์ที่ https://<user>.github.io/GaC-srtool/ ไม่เสียค่าใช้จ่ายตลอดชีพ!

⚙️ ตั้งค่าการเชื่อมต่อ API Server
