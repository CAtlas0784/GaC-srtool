🌐 วิธีนำขึ้นโฮสต์ GitHub Pages (ฟรี 100%)

สามารถเปิดใช้งานเว็บนี้บนอินเทอร์เน็ตได้โดยไม่ต้องเสียค่าโฮสต์ใดๆ

  1. 1. Create GitHub Repository:
    Create new repo e.g. GaC-srtool
  2. 2. Push to GitHub:
    git remote add origin https://github.com/<user>/GaC-srtool.git
    git add . && git commit -m "Init" && git push -u origin main
  3. 3. Enable GitHub Pages:
    Go to Repo > Settings > Pages > Source: Deploy from a branch > Branch: main / (root) > Click Save
  4. 4. Done:
    Your dashboard will be online at https://<user>.github.io/GaC-srtool/!
